# Канбан-доска для управления задачами

Веб-приложение для управления задачами в стиле канбан-доски. Позволяет создавать, редактировать, отслеживать и удалять задачи с различными статусами.

## Основные функции

### 1. Аутентификация пользователей
- **Регистрация** - создание нового аккаунта с проверкой логина и пароля
- **Вход в систему** - авторизация существующих пользователей
- **Выход из системы** - завершение сессии с подтверждением
- **Защита маршрутов** - доступ к доске только для авторизованных пользователей

### 2. Управление задачами

#### Создание задачи
- Заполнение названия задачи (обязательное поле, минимум 3 символа)
- Добавление описания (опционально)
- Выбор категории: Web Design, Research, Copywriting
- Выбор даты выполнения через календарь
- Автоматическое сохранение задачи на сервере

#### Редактирование задачи
- Изменение статуса задачи (5 статусов: Без статуса, Нужно сделать, В работе, Тестирование, Готово)
- Редактирование описания
- Изменение даты выполнения
- Сохранение изменений с проверкой на пустые поля

#### Удаление задачи
- Удаление задачи с подтверждением действия
- Мгновенное обновление доски после удаления

#### Просмотр задач
- Отображение задач в виде колонок по статусам
- Карточка задачи содержит: категорию, название, дату выполнения
- Клик по карточке открывает детальный просмотр задачи

### 3. Организация задач

#### Категории задач
- **Web Design** - задачи по веб-дизайну (оранжевый цвет)
- **Research** - исследовательские задачи (зелёный цвет)
- **Copywriting** - задачи по копирайтингу (фиолетовый цвет)

#### Статусы задач
- Без статуса - новые задачи
- Нужно сделать - запланированные задачи
- В работе - задачи в процессе выполнения
- Тестирование - задачи на проверке
- Готово - выполненные задачи

### 4. Кэширование данных
- Кэширование списка задач на 5 минут
- Уменьшение количества запросов к серверу
- Автоматическое обновление кэша при изменениях

### 5. Календарь
- Выбор даты выполнения задачи
- Визуальное выделение выбранной даты
- Отображение текущей даты
- Навигация по месяцам
- Срок исполнения отображается в карточке задачи

## Дополнительные функции

### 1. Обработка ошибок
- Отображение понятных сообщений об ошибках от сервера
- Автоматический выход при истечении сессии (401 ошибка)
- Кнопка "Повторить попытку" при ошибках загрузки
- Валидация полей перед отправкой на сервер

### 2. Защита от некорректного ввода
- Проверка на пустые поля и поля с пробелами
- Минимальная длина названия задачи - 3 символа
- Обрезка пробелов в начале и конце строк

### 3. Анимация загрузки
- Спиннер при загрузке задач
- Плавная анимация появления карточек
- Индикатор загрузки при создании/обновлении задач

### 4. Адаптивный дизайн
- Десктопная версия (от 1200px) - колонки расположены горизонтально
- Планшетная версия (от 660px) - горизонтальный скролл колонок
- Мобильная версия (до 495px) - кнопка создания задачи внизу экрана

### 5. UI/UX улучшения
- Карточки задач с цветовой индикацией категорий
- Модальные окна для создания и редактирования задач
- Подтверждение выхода из системы и удаления задачи
- Отображение полного текста почты при наведении (если текст не помещается)
- Сообщение "Новых задач нет" при пустой доске

### 6. Страница 404
- Кастомная страница для несуществующих маршрутов
- Ссылка для возврата на главную страницу
- Единый стиль с основным приложением

### 7. Управление сессией
- Автоматическое перенаправление на страницу входа при отсутствии токена
- Хранение данных пользователя в localStorage
- Защита приватных маршрутов через ProtectedRoute

### 8. Кэширование и оптимизация
- Кэширование ответов API для уменьшения нагрузки
- Принудительное обновление кэша при изменениях
- Оптимистичное обновление интерфейса

## Технологии

- **React 18+** - библиотека для построения интерфейсов
- **React Router DOM v6** - маршрутизация
- **Styled Components** - стилизация компонентов
- **Context API** - управление состоянием
- **REST API** - взаимодействие с сервером
